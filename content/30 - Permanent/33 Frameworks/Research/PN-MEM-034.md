# PN — Statistical analysis uses the Wilcoxon signed-rank test (non-parametric,…

Statistical analysis uses the Wilcoxon signed-rank test (non-parametric, paired) given ordinal metrics and limited sample size; it reports effect size r=Z/sqrt(N) (thresholds 0.1/0.3/0.5), bootstrap 95% CIs, and Holm-Bonferroni correction for multiple comparisons.
