# PN — Contextual anchoring is a prompt strategy that prepends concise…

Contextual anchoring is a prompt strategy that prepends concise operational definitions of the response classes before the question, reducing semantic ambiguity in ordinal/close classes; it is PUMA's canonical baseline strategy.
