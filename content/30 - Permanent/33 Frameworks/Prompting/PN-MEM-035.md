# PN — Carbon footprint is measured with an offline emissions tracker activated…

Carbon footprint is measured with an offline emissions tracker activated per run and persisted; offline mode is chosen for reproducibility and privacy, using a region-specific emissions factor (~0.17 kgCO2eq/kWh).
