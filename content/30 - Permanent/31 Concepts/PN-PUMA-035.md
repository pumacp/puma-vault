# PN — PUMA's sustainability measurement is explicitly bounded: it covers the…

PUMA's sustainability measurement is explicitly bounded: it covers the single inference host only and excludes data-center overhead (PUE), networking, and amortised training cost; the country code is an average grid factor, not real-time marginal intensity.
