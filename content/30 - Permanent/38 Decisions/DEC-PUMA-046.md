# DEC — PUMA Community is a separate GitHub repo (single source of truth) with…

PUMA Community is a separate GitHub repo (single source of truth) with downstream mirrors to Hugging Face Datasets, Zenodo (quarterly DOI snapshots), and Kaggle, chosen to run at zero perpetual infrastructure cost on free public services and keep the academic baseline bit-for-bit recoverable.
