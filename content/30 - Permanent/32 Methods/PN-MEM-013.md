# PN — The triage task uses a public dataset of 50,000+ real issues from…

The triage task uses a public dataset of 50,000+ real issues from open-source foundation projects (stable DOI, Creative Commons); each issue has title, description, a four-level priority (Critical/Major/Minor/Trivial) and contextual metadata.
