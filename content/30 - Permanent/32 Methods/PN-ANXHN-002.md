# PN — Install and start with one command: clone github.com/pumacp/puma then run…

Install and start with one command: clone github.com/pumacp/puma then run ./start_puma.sh, which verifies Docker, auto-detects NVIDIA GPU, pulls the Ollama image, builds runner/dashboard images, and brings up the three containers; first boot 5-15 min, dashboard at http://localhost:8501.
