# PN — PUMA Info traceability

PUMA Info traceability: each orchestrator run records the input file path and its sha256 alongside the produced output, the output tree mirrors the source tree, and a machine-readable SKILL.md path-contract declares where sources/prompts/outputs live, so any artifact traces back to its exact origin.
