# PN — Hypotheses follow Popper's demarcation criterion: each is a refutable null…

Hypotheses follow Popper's demarcation criterion: each is a refutable null (H0) with an alternative (H1); rejecting H0 only means observed data are incompatible with it under defined conditions, not universal validation.
