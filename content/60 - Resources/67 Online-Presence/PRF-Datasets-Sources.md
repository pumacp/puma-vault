# PRF — Benchmark dataset sources (public)

PUMA evaluates on two public datasets, both citable:
- **Jira Social Repository** — issue-triage source data (50,000+ real issues with priority labels). DOI **10.5281/zenodo.5901893** (https://doi.org/10.5281/zenodo.5901893).
- **TAWOS** — story-point estimation source data (user stories with assigned points), SOLAR group: https://github.com/SOLAR-group/TAWOS.
